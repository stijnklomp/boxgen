# Local web UI (`boxgen serve`) for v2

**Status:** accepted, 2026-10-18. Amends ADR-0001: the HTTP server returns, for exactly one command.

SYS-1.0 anticipates this step: the generator contract lists `boxgen serve` as the v2 local web UI (`docs/spec/docs/generator.md` §5), the workflow calls it the Bento3D-style editor over the same division tree (`docs/spec/docs/workflow.md`), and spec ADR-0009 says the UI consumes the same spec. With the calibration coupon passed (2026-10-18), `boxgen serve` is built as a single Rust binary (axum + tokio) that serves an embedded static frontend (vanilla ES modules + SVG; no Node, no CDN) plus the Rust API, binding `127.0.0.1` only: one local user, no auth, no database, no broker, no compose.

**The UI owns no geometry and no rules.** Every edit is validated by `spec.rs`/`tree.rs` through the API; every build runs through the one `run_build` pipeline, so `box.py`, `report.json`, and the CLI output stay byte-identical (pinned by the golden tests). The fixed architecture — walls, radii, lip, base zone, divider coves, print recipe — stays closed and is shown read-only; the variable surface is footprint, height, division tree, lid, ribs, and contents, anchored on the calibrated preset 4×4 · 6U · lid + ribs. Geometry parameter sliders would be a system change (SYS-1.1, a spec ADR, and re-calibration) and are explicitly out of scope.

**Consequences:** axum and tokio return to the dependency tree for this one command — ADR-0001 is amended, not reversed: still no sqlx/Postgres, Valkey, RabbitMQ, OpenAPI, pact, migrations, compose, or k8s. `docker/ui.Dockerfile` and `scripts/boxgen-ui.sh` add a second image and a one-command run (runtime FROM the pinned `boxgen/freecad:1.0.0`). The UI adds API tests to the existing gate. `docs/spec/` is untouched and `SYSTEM_VERSION` stays `SYS-1.0`; the five contract commands keep their names and argument shapes, and `serve` is the one non-contract v2 command.

**Rejected:** a separate repository or a wrapper around the CLI binary (stdout parsing would duplicate the report shapes and drift from the contract, and the spec already names `serve` a `boxgen` command); live in-browser geometry (a second implementation that would misrepresent what FreeCAD produces); browser downloads instead of files in the project workspace (the mounted repo is the single source of truth); exposing architecture parameters now (invalidates the coupon calibration; a SYS-1.1 project if ever wanted).
