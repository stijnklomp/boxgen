# Boxes

Each box lives in `boxes/<box-id>/`:

```
boxes/<box-id>/
  spec.yaml        source of truth, including the division tree
  box.step         archived solid model (body + lid)
  body.stl         print file for the body
  lid.stl          print file for the lid
  notes.md         contents, print date, filament, coupon result, mass/time
```

`build/<box-id>/` holds generated files (`box.py`, `box.FCStd`, raw exports) and is never edited by hand.

`boxes/INDEX.md` is generated by `boxgen index`. Do not edit it manually.

The system standard is [`docs/standard.md`](../docs/standard.md); the spec schema and CLI are in [`docs/generator.md`](../docs/generator.md). Start from [`templates/box-spec.yaml`](../templates/box-spec.yaml).
