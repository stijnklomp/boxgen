# Gridfinity is the base and stacking interface

We adopt the Gridfinity 42 × 42 × 7 mm base profile and stacking lip as the only standardised interface between bodies, baseplates, and other Gridfinity parts. The alternative was a bespoke stacking lip, which would have locked the system to our own parts and lost the open ecosystem. The body walls, lids, compartments, and print recipe remain our own design; only the base and lip are standard.

**Consequences:** every body must be generated from the standard base and lip profiles, not redrawn. The lip wall is constrained to 2.0 mm to preserve the standard opening (see ADR-0007). The system can use community baseplates and bins, and our bodies can sit on any Gridfinity baseplate.
