# YAML specs plus a FreeCAD Python master; the generator emits FreeCAD Python

The source of truth is one YAML spec per box plus a FreeCAD Python master module in git. The generator (`boxgen`, a Rust CLI) validates the spec and emits a FreeCAD Python build script; `freecadcmd` runs it and exports STEP and STL. `.FCStd`, STEP, and STL are generated artifacts, not sources. FreeCAD is the geometry engine; the generator never implements a mesh kernel, because the swept lip profile, fillets, and booleans are exactly where a hand-rolled kernel becomes fragile. The generator is a CLI first, with YAML files in git and no database; it lives in a separate repository forked from the Rust template and stripped of the server, Postgres, Valkey, and RabbitMQ features. A local web UI with the Bento3D-style division editor is v2 and consumes the same spec.
