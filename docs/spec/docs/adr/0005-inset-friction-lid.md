# Inset friction lid, no latch or magnet

The lid is a removable plate that sits inside the lip zone, 1 mm below the lip top, with a 2 mm skirt, a 20 mm finger hole, and a 0.30 mm per-side friction fit. It does not carry stack load: the next body's base rests on the body's lip, not on the lid. No latch, magnet, hinge, or screw is used. A latch system was rejected because it adds parts, protrusions, and failure modes, and the boxes are for storage rather than transport; if a box must be moved, the lid can be taped or strapped.

**Consequences:** the lid is not watertight or child-resistant; the body can be used open without modification. The lip/lid interface is fixed, so changing it later means reprinting bodies, not just lids.
