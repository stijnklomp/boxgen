# Maximum-thickness shell: 2.0 mm walls, 1.2 mm base side shell

All walls above the base are 2.0 mm, and the floor is 2.0 mm integral with the base top: body wall, lip wall, floor, dividers, and lid. The base zone's side shell is **1.2 mm**, the maximum the standard Gridfinity base profile allows before its internal fillet collapses; the master applies a 0.4 mm minimum fillet to the hidden cavity. A thicker side shell self-intersects the profile's chamfers. The **floor is 2.0 mm and integral with the base top**, so the base height and interior depth are unchanged: the floor is cut into the top of the base profile rather than added above it. The lip's 2.0 mm is the maximum that keeps the standard opening able to accept a mating base (about 2.25 mm is the hard limit). The earlier 3.2 mm body / 2.0 mm lip step (ADR-0004) was rejected because it adds mass and print time where it does not help, and leaves the floor and foot thinner than the walls. The earlier idea of a 2.0 mm base side shell was rejected because the standard base profile cannot accommodate it; the base is a locating feature, not the primary load path, and the 2.0 mm floor at its top carries the load. If the coupon shows floor deflection under 10 kg, the only permitted change is a 2.4 mm floor, added as a 0.4 mm slab above the integral 2.0 mm floor, with a re-run of the coupon.

**Research note:** common Gridfinity bins use 1.0–2.0 mm walls; the Fusion Gridfinity Generator caps at 2.0 mm; 2.6 mm designs exist but deviate from the standard fit. See [`docs/research/gridfinity-wall-thickness.md`](../research/gridfinity-wall-thickness.md).

**Status:** accepted; supersedes [ADR-0004](0004-heavy-duty-shell.md).
