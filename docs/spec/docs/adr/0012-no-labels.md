# No labels or colour coding

Bodies carry no label recess, no embossed text, and no category colour scheme. Identification is by the generated box index and the contents themselves. A label recess changes the body architecture and adds a non-structural feature to every body; embossed text ties a body to its contents; colour coding adds filament inventory and print changes. If labelling is needed later, an adhesive label can be applied to a flat side or the lid without changing the architecture.
