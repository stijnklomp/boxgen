# Compartment maps are recursive division trees

A compartment map is a recursive division tree: a compartment is a rectangle; it can be split along one axis into two child compartments; each child can be split again. Each split stores the axis and the divider position in millimetres, measured from the parent rectangle's origin to the divider's near face. This matches the Bento3D-style "divide in half, then move the divider" workflow, supports arbitrary compartment sizes (not just uniform cells), and guarantees that every divider spans its parent rectangle and connects to the outer wall through the tree — no floating dividers. A uniform character grid was rejected because it cannot represent exact non-uniform compartment sizes; a flat rectangle list was rejected because moving one divider would require manually recomputing every affected rectangle. The tree is the canonical spec; a grid or array view is a rendering of it.
