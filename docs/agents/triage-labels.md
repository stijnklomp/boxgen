# Triage Labels

The skills speak in terms of five canonical triage roles. This repository uses the GitHub labels below.

| Skill role | Label in this repo | Meaning |
| --- | --- | --- |
| `needs-triage` | _(not used)_ | A maintainer triages new issues directly; no label is applied. |
| `needs-info` | _(not used)_ | Ask for the missing information in a comment instead. |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent. |
| `ready-for-human` | `ready-for-human` | Human checkpoint: requires physical work (printing, measuring). |
| `wontfix` | `wontfix` | Will not be actioned. |

The GitHub defaults (`bug`, `documentation`, `enhancement`, `good first issue`, `help wanted`, `question`, `duplicate`, `invalid`) remain available for ordinary classification.

When a skill mentions a role (for example "apply the AFK-ready triage label"), use the corresponding label string from the table. Do not invent new triage labels without adding them to this file.
